# Academic Template Index

These templates are clean structural starting points, not finished slides. Replace every square-bracket placeholder, verify all evidence, and adapt density to the actual material. Never deliver placeholder paths or values.

Use `academic-light` by default. Use the dark architecture template only when the technical field, venue, and projector justify it. Keep one visual system across a deck.

| File | System | Best use | Required asset |
|---|---|---|---|
| [cover-light.tpl](cover-light.tpl) | Academic light | Conference or defense opening | None |
| [section-light.tpl](section-light.tpl) | Academic light | Long-defense section break | None |
| [gap-light.tpl](gap-light.tpl) | Academic light | Literature boundary and research gap | Optional small evidence figure |
| [method-light.tpl](method-light.tpl) | Academic light | Three-stage method or experimental design | None |
| [figure-light.tpl](figure-light.tpl) | Academic light | One dominant scientific figure | One figure image |
| [comparison-light.tpl](comparison-light.tpl) | Academic light | Baseline comparison, ablation, or robustness | One comparison chart/table image |
| [contribution-light.tpl](contribution-light.tpl) | Academic light | Evidence-backed contributions or synthesis | None |
| [limitations-light.tpl](limitations-light.tpl) | Academic light | Limitations and threats to validity | None |
| [qa-light.tpl](qa-light.tpl) | Academic light | Intellectual close and Q&A | None |
| [architecture-dark.tpl](architecture-dark.tpl) | Academic technical | System architecture or data flow | Optional architecture image |
| [defense-navigation-light.tpl](defense-navigation-light.tpl) | Institutional defense | Committee-oriented content with persistent chapter location | None |
| [result-dominant-light.tpl](result-dominant-light.tpl) | Academic light | Wide result figure with two verified metrics | One result figure |
| [progress-risk-light.tpl](progress-risk-light.tpl) | Institutional defense | Progress, risk, mitigation, and next milestone | None |

Choose the layout by narrative role, not by visual novelty. For a short conference talk, omit section dividers and agenda slides. For a defense, use section dividers sparingly and keep appendix slides visually consistent with the main deck.
